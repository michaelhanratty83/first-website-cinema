# First Website Cinema

This project is a small cinema website built using HTML, CSS, and JavaScript. It includes pages for the homepage, showing now, coming soon, prices, and contact information.

## Pages Included
- Home
- Showing Now
- Coming Soon
- Prices
- Contact Us
